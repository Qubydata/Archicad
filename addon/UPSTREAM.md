# Upstream

The Tevavid Archicad add-on is built on the Archicad add-on of Tapir
(https://github.com/ENZYME-APD/tapir-archicad-automation), MIT licensed, see
LICENSE-TAPIR. This folder started as a copy of its `archicad-addon` folder
(Sources, Tools, CMakeLists.txt, devkits.json) and `tools/devkits.py` at commit
9abb12551dd949e2796e8c621557531d05837544 (2026-11-09). The commit after the copy
holds every Tevavid change, so upstream fixes can be brought over by diffing.
